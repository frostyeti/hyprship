# hypership

Hyprship is a platform for shipping. Turn a VPS into a business or homelab.  


## Use cases

- Frictionless deployments of apps to docker, kubernetes, and servers.
- Centralized secrets management and configuration management.
- Remote script execution and management.
- Inventory and management of devices and servers.
- Workflow and automation engine for IT operations and DevOps.
- Notifications and alerts for deployments, jobs, and other events.
- Role-based access control and permissions for projects and resources.
- Multi-tenant support for agencies and managed service providers.
- API for integrating with other tools and platforms.

## Ideation

Hypership should priortize these feature first:

- identity
- groups
- projects
- secrets, environments, and configurations
- devices
- jobs
- workflows
- deployments
- app catalog and marketplace
